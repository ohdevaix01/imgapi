imgapi

Generador de imagenes con IA. API propia en Go, 8 MB, con cache y failover entre proveedores gratis.

Como se usa desde tu codigo

# lo mas simple: te devuelve la imagen
curl "http://TU_IP:8080/generate?prompt=un+gato+negro&width=1024&height=1024" -o gato.jpg

# con seed fijo, para repetir la misma imagen
curl "http://TU_IP:8080/generate?prompt=un+gato+negro&seed=42" -o gato.jpg

# forzando un proveedor
curl "http://TU_IP:8080/generate?prompt=un+gato+negro&provider=horde" -o gato.jpg

# respuesta JSON con la url de la imagen
curl "http://TU_IP:8080/generate?prompt=un+gato+negro&format=json"

# JSON con la imagen en base64
curl "http://TU_IP:8080/generate?prompt=un+gato+negro&b64=1"

# si configuraste API_KEY
curl -H "X-API-Key: tu_clave" "http://TU_IP:8080/generate?prompt=un+gato+negro" -o gato.jpg

Endpoints

GET/POST /generate genera o devuelve de cache. GET /image/{id} sirve una imagen ya generada. GET /health estado y proveedores. GET /stats contadores.

Parametros: prompt (obligatorio), width, height (256 a 2048, multiplos de 8), seed, model, provider, format=json, b64=1. En POST se acepta JSON con esos mismos campos.

Cache: la misma combinacion de prompt, tamano, seed y proveedor no se vuelve a generar. Vive en disco y sobrevive a los reinicios. Se controla con CACHE_TTL.
